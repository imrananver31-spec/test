# BlogOkna — демоверсия редизайна «Rain / Glass / Architecture»

Одностраничная демоверсия редизайна сайта https://блогокна.рф/ — концепция для показа партнёру.

## Запуск

1. Дважды кликнуть `start.bat` — откроется браузер на http://localhost:5173
   (или в терминале: `node server.js`). Нужен Node.js, сторонние пакеты не требуются.
2. Остановить — закрыть окно консоли (или Ctrl+C).

Страницу нужно открывать именно через локальный сервер: при открытии `index.html`
двойным кликом (file://) браузер запрещает WebGL читать изображение, и первый экран
переключается на упрощённый режим (фото + капли без преломления).

## Что внутри

- `index.html` — разметка, 7 секций: Hero, Услуги, Проекты, Калькулятор, Этапы, Контакты, Футер.
- `js/rain.js` — первый экран: дом за мокрым стеклом.
  - Камера медленно отъезжает от дома (≈11 с, плавное замедление), дальше — едва заметный дрейф
    и параллакс от курсора. Сцена — 4K-фото с мип-мапами (без мерцания при движении).
  - Капель нет: дом за чистым стеклом в резком 4K, только лёгкая дымка запотевания внизу.
    Симуляция капель осталась в коде и выключена (счётчики в `simOptions` равны 0).
  - Рендер до 2× плотности пикселей (3840×2160 на 4K-экране). На слабых устройствах качество
    снижается автоматически; при `prefers-reduced-motion` — статичный кадр; без WebGL — CSS-фолбэк.
- `js/main.js` — интро, отъезд камеры, анимации прокрутки (GSAP + ScrollTrigger, Lenis), меню,
  калькулятор, форма.
- `css/style.css` — стили, адаптив, состояния.
- `assets/hero/` — фото первого экрана в 1600 / 2560 / 3840 px (выбирается под экран).
- `assets/` — фото работ, шрифт Inter, логотип, библиотеки.
- `server.js` — минимальный статический сервер.

## Демонстрационные функции

- **Калькулятор** — коэффициенты условные, суммы не являются ценами BlogOkna (помечено в интерфейсе).
  Кнопка «Запросить точный расчёт» переносит параметры в комментарий формы.
- **Форма заявки** — валидация и маска телефона работают, но данные никуда не отправляются
  (помечено в интерфейсе). Для боевой версии нужен обработчик заявок.
